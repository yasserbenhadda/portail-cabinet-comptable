## 🔧 Technologies Documentées

### **Backend**
- **Spring Boot 3.2+** : Framework principal
- **Java 17** : Langage de programmation
- **PostgreSQL** : Base de données relationnelle
- **JWT** : Authentification et autorisation
- **Spring Security** : Sécurité des endpoints
- **Spring Data JPA** : Accès aux données
- **Maven** : Gestion des dépendances

### **Architecture**
- **MVC Pattern** : Modèle-Vue-Contrôleur
- **Layered Architecture** : Architecture en couches
- **Repository Pattern** : Accès aux données
- **Service Layer** : Logique métier
- **DTO Pattern** : Transfert de données
